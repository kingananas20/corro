The `inline` attribute was malformed.

Erroneous code example:

```rust
#[inline()] // error: expected one argument
pub fn something() {}

fn main() {}
```

The parenthesized `inline` attribute requires the parameter to be specified:

```rust
#[inline(always)]
fn something() {}
```

or:

```rust
#[inline(never)]
fn something() {}
```

Alternatively, a paren-less version of the attribute may be used to hint the compiler about inlining opportunity:

```rust
#[inline]
fn something() {}
```

For more information see the [`inline` attribute](https://doc.rust-lang.org/reference/attributes/codegen.html#the-inline-attribute) section of the Reference.
