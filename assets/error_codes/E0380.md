An auto trait was declared with a method or an associated item.

Erroneous code example:

```rust
unsafe auto trait Trait {
    type Output; // error!
}
```

Auto traits cannot have methods or associated items. For more information see the [opt-in builtin traits RFC](https://github.com/rust-lang/rfcs/blob/master/text/0019-opt-in-builtin-traits.md).
