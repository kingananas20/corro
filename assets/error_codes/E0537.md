An unknown predicate was used inside the `cfg` attribute.

Erroneous code example:

```rust
#[cfg(unknown())] // error: invalid predicate `unknown`
pub fn something() {}

pub fn main() {}
```

The `cfg` attribute supports only three kinds of predicates:

* any
* all
* not

Example:

```rust
#[cfg(not(target_os = "linux"))] // ok!
pub fn something() {}

pub fn main() {}
```

For more information about the `cfg` attribute, read the section on [Conditional Compilation](https://doc.rust-lang.org/reference/conditional-compilation.html) in the Reference.
